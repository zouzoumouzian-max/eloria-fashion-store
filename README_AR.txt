حزمة ÉLORIA PWA - الإصدار التجريبي الثالث

محتويات الحزمة:
- index.html: المتجر الأصلي كما هو، دون تغيير التصميم أو المنتجات أو الأقسام أو الوظائف.
- manifest.json: تم تغيير معرّف التطبيق فقط إلى معرّف جديد لتمييز محاولة التثبيت.
- service-worker.js: تم تحديث اسم ذاكرة التخزين المؤقت إلى eloria-pwa-v3.
- icon-192.png و icon-512.png: أيقونات التطبيق.

طريقة الرفع إلى GitHub Pages:
1) افتح مستودع eloria-fashion-store في GitHub.
2) ارفع الملفات الخمسة الموجودة في هذه الحزمة إلى جذر المستودع.
3) وافق على استبدال الملفات القديمة بالملفات الجديدة عند السؤال.
4) انتظر حتى ينتهي نشر GitHub Pages.
5) افتح رابط المتجر وأعد تحميل الصفحة، ثم جرّب التثبيت.

مهم:
- لا تحذف المستودع ولا تغيّر اسم المجلد أو رابط الموقع.
- لا تمسح بيانات Chrome ولا بيانات المواقع.
- تغيير معرّف التطبيق ينشئ هوية تثبيت مختلفة، لكنه لا يضمن وحده حل رسالة Chrome؛ إذا استمرت المشكلة سنفحص حالة التثبيت وإصدار Chrome.
